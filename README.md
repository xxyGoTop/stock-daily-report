# A股日报分析器

自动抓取行情、公告、资金流与热点新闻，按三条策略线筛出候选股，输出**可视化 HTML 日报**和**可直接粘贴的交易便签**。

> ⚠️ 本项目是技术框架的自动筛选工具，**不构成任何投资建议**。所有买卖价位均为程序按规则推算，请自行判断与风控。

## 它能做什么

每次运行会生成一份日报，包含：

- **今日热点新闻 15 条** —— 排在所有分析之前，先看宏观再看个股
- **三个选股模块**
  - 模块一 · **正股**：纯技术面（五日线多头共振 + 陶博士顺向火车轨/火车每日观察/蓝色钻石 + RPS 相对强度）
- **陶博士 241005 择股**：先按板块指数 RPS5 选主流板块，再选「率先一年新高」或「高 RPS 深调回升」，
  最后**只看当天交易日涨幅榜第一版（29 只）**，挤不进第一版的不纳入
  - 模块二 · **ST 股**：ST 摘帽/重整预期，含事件进展与时间窗
  - 模块三 · **收购 / 股权转让 / 重整**（非 ST 的事件驱动正股）
- **每只正股的「炒作预期」和「为何涨/为何跌」** —— 见下方说明
- **指数与 ETF 信号**：大盘中期是否可买、重点 ETF 的技术线买卖位
- **每只票的买入价 / 卖出价 + 理由**、进展阶段、下一步动作、预期窗口
- **行业 / 主力资金流 / 筹码集中度**
- **雪球大 V 观点**（粉丝 ≥ 4000，需手动登录一次）

## 快速开始

需要 Node.js ≥ 18。

```bash
npm install
npm start
```

跑完会自动打开当天的 HTML 日报，文件同时存在 `output/YYYY-MM-DD/latest.html`。

首次运行若想要雪球观点，程序会优先使用 `config/xueqiu.local.json` 里的 cookie 直连接口；没有有效 cookie 时才会弹浏览器让你登录（**优先扫码**，Playwright 窗口里滑块常被风控拒绝）。不需要观点可加 `--no-xueqiu` 跳过。

| 命令 | 作用 |
|------|------|

| `npm run stock -- 贵州茅台 600519` | 只分析指定几只（**支持中文名**） |

### 自选股支持中文名

代码和中文名可以混着写，用空格或逗号分隔，中英文标点都认：

```bash
npm run stock -- 贵州茅台 远东股份 600519
npm run stock -- 高争民爆、雪浪环境
npm run stock -- --codes=英力特,海鸥住工
```

中文名先在当天报告里找，找不到再走腾讯/新浪/东财的联想接口解析成 6 位代码。实在识别不出会提示跳过，不影响其余股票。

### 尾盘选股 `npm run tail`

在 14:30~15:00 这个决策窗口跑，按**当日成交量 + 大盘环境 + 五日线状态**筛出现在就能下单的票。报告同时给出：

- **今天最强板块**：今日涨幅、上涨扩散度和主力资金共同确认
- **尾盘异动板块**：今日涨速显著高于近 5 日均速，并有上涨家数和资金流确认
- **板块共振推荐**：仅从通过个股五日线、量能、尾盘位置硬门槛的股票中推荐，不因板块上涨放宽个股标准

```bash
npm run tail                # 默认输出 10 只
npm run 尾盘                # 同上
npm run tail -- --max=5     # 只要前 5 只
npm run tail -- --fast      # 少扫一些，约 15 秒出结果
npm run tail -- --no-market # 跳过大盘分析，更快
npm run tail -- --no-open   # 不自动打开 HTML
```

和其他命令的关键区别：**买入点是当场可挂的价位**，不是明日回踩价；量能会按已过交易时间折算成全天量，所以盘中提前跑也不会低估当日量。

结果同时出 HTML / 文本 / JSON 三份，默认自动弹出 `output/<日期>/latest-tail.html`（快捷入口 `output/latest-tail.html`）。HTML 版把买入点、止损止盈、仓位、五日线、量能、日内位置、资金、买入理由和风险提示按卡片排好，比纯文本好扫。

### 板块强度 `npm run boards`

只统计**当天交易日**行业板块强度（不跑选股），自动打开 HTML：

```bash
npm run boards                # 前 10 强度板块
npm run 板块                  # 同上
npm run boards -- --top=15    # 前 15
npm run boards -- --concept   # 行业+概念一起排
npm run boards -- --no-market # 跳过市场风格与量能统计
npm run boards -- --leaders=2 # 每个板块列 2 只龙头（默认 3）
npm run boards -- --no-leaders # 跳过龙头筛选（更快）
npm run boards -- --no-open   # 不自动打开浏览器
```

顶部先给出**当前市场风格与量能**：

- **市场风格**：大小盘、成长价值两个维度，用宽基指数横向比较得出
  （小盘＝中证1000+国证2000，大盘＝上证50+沪深300；成长＝创业板指+科创50，价值＝上证50+中证红利）
- **量能**：两市成交额与近 5 日均量对比，判定显著放量 / 温和放量 / 持平 / 缩量。
  盘中会按已过交易时间折算成全天量，所以上午跑也不会低估
- **主导方向**：把当日板块归入科技 / 医药 / 高端制造 / 消费 / 周期资源 / 金融地产 / 基建公用，
  看谁在前十超配且跑赢全市场；都不明显时直接标「无明确主导方向」，不硬造主线

每张板块卡片给出：

- **综合强度**（涨幅 + 上涨扩散 + 主力资金 + 相对近 5 日加速）
- **是否分化**：齐涨 / 一般 / 分化（少数票硬拉）
- **资金情况**：主力净流入/流出及金额
- **是否走强**：走强 / 冲高分化 / 震荡 / 走弱
- **龙头股**：默认列 3 只，标注涨停/连板、成交额、主力净流入、流通市值和入选理由

#### 龙头股是怎么选的

东财板块快照自带的「领涨股」只是涨幅第一名，一只微盘股拉涨停就能占位，不代表资金认可。所以这里拉板块成分股重新评分：

- **先过门槛**：剔除次新股（N/C 开头）、流通市值 < 15 亿、成交额 < 8000 万、停牌和退市整理股
- **再多因子打分**：涨幅分位 30 分 + 成交额分位 26 分（资金聚焦度）+ 主力净流入 + 涨停 8 分 + 每多一个连板 6 分（封顶 18）
- **分位都是板块内部比的**——龙头本来就是同板块比出来的，用绝对阈值在大小板块之间没法比
- **今天收绿的票不进榜**，哪怕它成交额最大
- 第一名没甩开第二名 8 分、也没涨停时，标成「**龙头待定**」，明说板块内部还在混战，不硬指一只

举例：通信线缆板块里中天科技成交额 89.8 亿远大于神宇股份的 6.1 亿，但神宇股份 20cm 涨停，最终龙头判给神宇股份——打板资金认的是涨停那只。

结果在 `output/<日期>/latest-boards.html`（快捷入口 `output/latest-boards.html`）。

### 当日复盘 `npm run review`

收盘后跑一次，回答「今天发生了什么、明天该盯什么」。只统计事实与归纳倾向，**不给个股买卖价**——买点仍然用 `npm run tail` / `npm run stock`。

```bash
npm run review                       # 今天的复盘，自动弹 HTML
npm run 复盘                         # 同上
npm run review -- --top=15           # 板块强度取前 15
npm run review -- --date=2026-09-10  # 复盘指定交易日的涨停/跌停梯队
npm run review -- --no-news          # 跳过热点新闻
npm run review -- --no-open          # 不自动打开浏览器
```

报告包含：

- **情绪打分**（0~100）：涨停家数、封板率、连板高度、赚钱效应、跌停压力五项加权，给出过热 / 偏热 / 中性 / 偏冷 / 过冷及对应的操作倾向。单看涨停数会被一字板低价股误导，所以封板率和跌停数一起参与打分
- **连板梯队**：按连板数分层，标注所属行业和首次封板时间，直接看出空间板在几板、断层在哪
- **今日主线**：涨停在行业上的聚集度 × 板块指数是否同步走强，两者都满足才标「已确认」，只有零星涨停的只算题材
- **风格与量能**：大小盘 / 成长价值倾向、两市成交额与近 5 日均量对比、资金主导大类
- **明日关注**：由情绪等级、主线确认情况和量能推导出的跟踪点与风险点

结果在 `output/<日期>/latest-review.html`（快捷入口 `output/latest-review.html`）。

> `--date` 只对涨停/跌停/炸板梯队生效；板块强度和量能走的是实时接口，拿不到历史值，跑历史日期时会提示。

三档筛选条件：

- **五日线**（硬门槛）——必须站上 MA5 且 MA5 向上，跌破的直接淘汰
- **当日量能**——量比 ≥1.05 起筛，折算全天量与 5 日均量对比，缩量的不要
- **日内位置**——收盘价在当日振幅区间的分位。尾盘收在低位说明最后半小时没人接，直接否决

输出分两块。**【尾盘可买】**是现价就能下手的，每只给买入区间、止损止盈、建议仓位（跟着大盘信号浮动，大盘 avoid 时降到 0）、买入理由和风险提示——理由里只放支持做多的因子，利空一律进风险提示，两者不混。**【观察区】**是技术面合格但当前价位追不得的（多为乖离 >6.5%），标明回踩到哪个价位可以再评估。

主力大幅净流出（占成交 ≤-5%）、连续涨停、逼近涨停板的会被直接剔除，不进任何榜单。

结果存在 `output/<日期>/tail_<时分秒>.txt`（和 `.json`），最近一次另存为 `output/latest-tail.txt`。

### 数据新鲜度提示

每份报告（日报、自选、尾盘）顶部都会显示一行「数据新鲜度」，说明**均线/MACD/KDJ 这些指标究竟基于哪一天的收盘计算**。

这一行有必要，是因为新浪的日K在盘中不返回当天那根（要等收盘后几分钟才补），而腾讯有 WAF 限流、东财节点时有不可用。三个源都不稳定的时候，很容易在毫不知情的情况下拿着昨天的均线做今天的决策。

判断用两条独立链路交叉验证：K线基准日取三个源里最新的那个，实时行情日期来自另一条链路的行情接口。当实时行情已经走到今天、K线却只到昨天时，会显式告警：

```
⚠ 数据新鲜度：实时行情已到 2026-09-07，但K线源最新只到 2026-09-04 ·
   均线/MACD/KDJ 等指标全部基于 2026-09-04 收盘计算，不含当日走势
```

看到这个告警说明当次结论不可用于当日盘中决策，隔几分钟重跑通常就好了。开盘前、周末和节假日跑不会告警，因为那时指标本来就该是上一交易日的。

## 「炒作预期」和「为何涨跌」是怎么算的

这两栏是为了回答「这票在炒什么、今天为什么动」，都基于公开数据推导，不是抓取的评论。

**炒作预期**：把个股的概念板块与今日热点新闻、涨幅榜板块做交集。命中就标为「热点题材命中」并附上对应新闻标题；没命中就退回列出自身概念/行业。再叠加 RPS 相对强度定位（中期强势主升 / 低位补涨 / 中期偏弱）和真实公告事件。

**为何涨/为何跌**：对八类因子各算一个「显著度」——数值越极端越显著，然后取最突出的几条组成文案：

| 因子 | 用到的数据 |
|------|-----------|
| 主力资金 | 净流入金额、占成交比、超大单是否同向 |
| 量能 | 量比 |
| 换手 | 换手率 |
| 相对强度 | RPS20 / 50 / 120 / 250 |
| 均线乖离 | 距 MA5 / MA10 / MA20 的偏离 |
| MACD | 金叉、临近金叉、绿柱缩短天数、红柱值 |
| 筹码 | 集中度 90、获利盘比例、成本区 |
| 题材 | 概念与热点新闻/热门板块的交集 |

因为文案里会写进具体数值，所以每只票的归因都不一样——如果你看到多只票输出同一句话，通常说明东财资金流接口那一批请求失败了，重跑一次即可（程序已做多域名轮换和重试）。

## 配置与隐私

- `config/xueqiu.local.json` 保存雪球 cookie，**已被 `.gitignore` 排除**，不会提交
- `data/trades.json`、`data/strategy-insights.json` 是你的交易台账，同样不提交
- `.xueqiu-browser-profile/` 是浏览器登录态目录，也不提交

仓库里只有 `config/xueqiu.local.example.json` 作为模板。

## 数据来源

东方财富（行情、K 线、资金流、概念、热点新闻）、巨潮资讯（公告）、腾讯/新浪（名称联想、实时报价）、雪球（大 V 观点）。全部为公开接口，请合理控制请求频率。
